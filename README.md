Kubeblast is a Kubernetes-native platform that makes running JMeter load tests efficient and effortless. 

Without the hassle — no scripting, no setup, just run and get results!

Features:
- Simplicy - Just upload your JMX file and Run
- Placement-control - Configure on which nodes to run your workloads
- Self-service - Allow teams to run load test by themselves in allowed scope. No admin interaction needed.
- Moderation - Set moderators to check JMX plan files before allowing execution.
- Friendly UI - Allows you to watch logs and get live status updates of your Load tests.
